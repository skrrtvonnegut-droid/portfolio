# Case studies

Case studies describe sanitized professional work through a consistent structure:

1. Problem and operational context
2. Constraints and risks
3. Design choices and trade-offs
4. Controls and validation
5. Outcomes and lessons

Raw internal documentation is not copied here. Exact names, production values, architecture identifiers, and private evidence are replaced with synthetic examples or expressed as reusable decision patterns.
