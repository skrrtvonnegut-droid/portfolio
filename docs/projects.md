# Featured Projects

The portfolio links to canonical public repositories rather than copying their code or documentation. Each project remains independently versioned, while this page explains what the work demonstrates as part of a broader professional practice.

## Microsoft 365 License Report

**Repository:** [skrrtvonnegut-droid/M365LicenseReport](https://github.com/skrrtvonnegut-droid/M365LicenseReport)

A PowerShell and Microsoft Graph reporting project for understanding Microsoft 365 license assignment, usage, cost, and governance. The project demonstrates how a technical inventory can become a decision-support tool rather than a one-time export.

**Capabilities shown:**

- Microsoft Graph authentication and data retrieval
- PowerShell automation and report generation
- license utilization and cost visibility
- governance-oriented output design
- reusable tooling with public documentation

## Prompt Library

**Repository:** [skrrtvonnegut-droid/prompt-library](https://github.com/skrrtvonnegut-droid/prompt-library)

A public registry for reusable prompts, skills, macros, schemas, and validation. The project treats natural-language automation as versioned infrastructure: artifacts have stable identities, explicit contracts, discoverability, and CI rather than living as untracked snippets.

**Capabilities shown:**

- prompt and workflow architecture
- schema-backed registries
- validation and CI/CD
- provenance and reusable interfaces
- technical writing for human and machine consumers

## The People’s Grimoire

**Repository:** [skrrtvonnegut-droid/the-peoples-grimoire](https://github.com/skrrtvonnegut-droid/the-peoples-grimoire)

An open-source architecture for user-owned coordination across SaaS applications. It explores how memory, tools, policy, and automation can form a coherent personal control plane without surrendering privacy or agency to a single platform.

**Capabilities shown:**

- system architecture and connector contracts
- privacy and trust-boundary design
- open-source project framing
- policy-governed automation
- interoperability and extensibility
